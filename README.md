# MetallBrücke

Türk metal işletmeleri için Almanya pazarı danışmanlık sitesi.

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS
- wouter (routing)
- lucide-react (icons)
- 2 dil: TR (default) + DE

## Deploy

Cloudflare Pages. Build komutu: `npm run build` → output: `dist/`

## Geliştirme

```bash
npm install
npm run dev   # http://localhost:5173
npm run build # production
```
